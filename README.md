# MarkdownLiveEdit

入力本文を保存・送信しない、ブラウザ内完結型のMarkdownエディタです。

## 起動

`index.html` をブラウザで開くだけで利用できます。

設置URLは `https://markdownliveedit.appx.jp/` です。
公開対象のファイルは、プロジェクトルートの公開ファイルと `icons/`、`vendor/` を対象サブドメインの公開ディレクトリへ配置します。

## 主な機能

- Markdownの入力とリアルタイムプレビュー
- CommonMark/GFM（表、タスクリスト、取り消し線、自動リンク等）の既存表示を維持
- GitHub形式の脚注・アラート、Pandoc/Markdown Extra系の定義リスト・略語を追加表示
- Pandoc形式の `$...$` と `$$...$$` の数式を同梱KaTeXで端末内表示
- プレビューのh3〜h6見出しに階層を見分ける装飾マークを表示
- PC・横長タブレットでは左右、スマートフォンでは上下のレスポンシブ表示
- MarkdownとDOMPurifyで安全化したHTMLのコピー
- 行番号、検索・置換、字下げ、行移動、行複製、自動括弧、書式ショートカット
- 初期状態では非表示の書式ヒントを、Markdown入力欄での `Ctrl` / `⌘` + `Shift` + `H` または画面上のボタンで切り替え、最終表示状態を端末に保存
- Markdown入力欄で `Ctrl` / `⌘` + `H` による置換、`Alt` + `↑ / ↓` による行移動、`Shift` + `Alt` + `↓` による行複製
- ライト／ダークテーマを切り替え、選択したテーマを端末に保存
- 太字、斜体、取り消し線、見出し、引用、リスト等を同じ操作でもう一度解除
- 未閉鎖コードブロック、壊れたリンク、見出し構造、画像代替テキスト等の簡易チェック
- キーボード操作、読み上げラベル、明確なフォーカス、ハイコントラスト、動きの抑制などWCAG 2.2 AAを目標にした設計
- `Esc` の後に `Tab` / `Shift + Tab` を押してエディタからフォーカス移動できるキーボードトラップ防止
- 編集後にページを閉じたり再読み込みしたりする場合の確認
- スマートフォンで編集欄とプレビュー間を移動するリンク
- PC・タブレット・スマートフォンへのPWAインストールと、公開アプリ資産を利用したオフライン起動

## プライバシー

入力本文は `localStorage`、Cookie、サーバーのいずれにも保存・送信しません。外部URLの画像は初期状態で遮断し、利用者が「外部画像：遮断中」を押して明示的に許可した場合だけ読み込みます。許可時は画像の接続先へIPアドレス等の通信情報が伝わる場合があります。

初回アクセス時は、データの取扱いと基本操作を案内する3段階のチュートリアルを表示します。完了またはスキップ後は、表示済み状態を `localStorage` に保存し、2回目以降は自動表示しません。また、書式ヒントの最終表示状態と選択した表示テーマも `localStorage` に保存します。入力本文は保存対象に含めません。ヘッダーの「?」ボタンからいつでも再表示できます。

PWA機能は、オフライン起動に必要なHTML、CSS、JavaScript、アイコン等の公開アプリ資産だけをブラウザのCache Storageへ保存します。Markdownの入力本文や利用者が入力したデータはキャッシュしません。

利用状況の把握にはGoogle Analytics（測定ID `G-3MLFE0ZZZ0`）を使用します。閲覧ページ、参照元、端末・ブラウザ情報、IPアドレス等がGoogleへ送信され、Cookie等が使用される場合があります。Markdownの入力本文はAnalyticsイベントへ含めず、広告向けGoogleシグナルと広告パーソナライズは無効にしています。

保存機能はありません。編集後にページを離れる際は確認を表示しますが、ページを閉じると入力内容は失われます。

## 補足

Markdown簡易チェックは、よくある入力間違いとアクセシビリティ上の注意を示す補助機能です。CommonMarkのすべての仕様を検証するものではありません。

同梱ライブラリのライセンスは `vendor/` に収録しています。

## 利用規約案

`terms.html` に草案を収録しています。`index.html` のフッターにある利用規約リンクはコメントアウトしているため、現在の画面には表示されません。草案は `noindex` 指定により検索結果への掲載を抑止しています。

正式公開前に草案中の角括弧（運営者名、制定日、施行日、管轄裁判所、連絡先）を確定し、必要な法務確認を行ってください。内容確定後は、必要に応じて `terms.html` の `noindex` 指定を解除します。

## 寄付案内

ヘッダーの「寄付」リンクから `donate.html` を表示します。寄付先サービスが未確定のため、現在は受付準備中であることを明示し、支払いリンクは掲載していません。受付開始時は、正規の寄付先URL、運営主体、決済事業者、手数料、個人情報の取扱いを確認してから更新してください。
